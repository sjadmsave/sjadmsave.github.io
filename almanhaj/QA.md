# فحص واجهة متجر المنهج

التاريخ: 2026-11-07. الفرع: `dev/almanhaj-material-store-20261107`.

## النتيجة

اكتمل تطوير واجهة المتجر بأسلوب قريب من متاجر أندرويد ومتجر بلاي، مع الحفاظ على هوية المنهج ومصدر التطبيقات. لم يُدمج التطوير في `main` ولم تُغيّر إعدادات النشر الإنتاجية.

| الفحص | النتيجة |
| --- | --- |
| الكتالوج والتحميلات السابقة | الملف مطابق للمصدر، وجميع التطبيقات العشرين محفوظة بمعرّفاتها وروابطها وبصماتها |
| إصدارات GitHub الحالية | تحقق من الإصدارات العشرين عبر API؛ كلها منشورة، وروابط APK تطابق الأصول الموجودة فيها |
| سلامة JavaScript والملفات الأساسية | اجتاز فحص smoke |
| قواعد الكتالوج والبحث والفرز | اجتازت 8 اختبارات آلية، تشمل الإدخالات المكررة وغير المنشورة والروابط غير الصالحة والبيانات الاختيارية التالفة |
| البحث العربي | البحث عن «تبيان» يعرض «تِبيان»؛ اختُبرت إزالة التشكيل والتطويل وأشكال الألف والأرقام آليًا |
| المحفوظات | إضافة التطبيق، ظهور العداد والقائمة، إزالة آخر عنصر وظهور الحالة الفارغة |
| التصنيفات | أربعة تصنيفات من البيانات؛ «مداخل العلوم» يعرض خمسة تطبيقات |
| الترتيب | فتح اللوحة، اختيار الأقدم، تحديث القائمة وإغلاق اللوحة |
| تفاصيل التطبيق | بيانات الإصدار والتاريخ والملاحظات وبصمات التحقق وروابط الإصدار والتحميل |
| الرجوع | يغلق التفاصيل والترتيب ويستعيد التركيز؛ اختُبر فتح رابط تطبيق مباشر وإغلاقه دون مغادرة المتجر |
| المظهر | التبديل إلى الداكن، قراءة الألوان المحسوبة، واستمرار الاختيار بعد إعادة تحميل المعاينة |
| الخطوط والأيقونات | تحميل الخط المحلي وأيقونات التطبيقات؛ يوجد بديل عند تعذر تحميل الأيقونة |
| أخطاء قراءة القائمة | حُقن كتالوج تجريبي غير صالح محليًا؛ ظهرت رسالة الخطأ وزر إعادة المحاولة، ثم عادت القائمة إلى 20 تطبيقًا بعد استعادة المصدر |
| مقاسات الهاتف | إطارات معاينة بعروض 320 و360 و390 و430 و768 بكسل؛ لم يظهر فائض تمرير أفقي |
| أهداف اللمس | فحص الأزرار الرئيسية وروابط التنقل والتحميل؛ لا يقل العرض أو الارتفاع عن 48 بكسل في معاينة 320 بكسل |
| أخطاء الواجهة في المتصفح | لم تظهر أخطاء JavaScript مسجلة من مصدر الموقع أثناء الفحوص |

## حدود التحقق

الفحص المرئي جرى في Chrome باستخدام إطارات معاينة تستجيب لأبعاد الهاتف؛ شريط التمرير التقليدي يقلّل مساحة المحتوى 15 بكسل. لم يُجرَ تثبيت على هاتف أندرويد فعلي. اختُبرت روابط الأصول عبر بيانات GitHub، ولم يُعَد تنزيل وفحص محتوى ملفات APK العشرين.

المعاينة المحلية تعمل عبر HTTP. ظهرت رسالة النسخ اليدوي عند عدم توفر الحافظة التلقائية؛ لم يُدّعَ نجاح نسخ بصمة إلى الحافظة في هذا السياق. المشاركة الأصلية وصلاحيات الحافظة تُعتمدان على المتصفح وHTTPS، ويلزم فحصهما على الهاتف بعد النشر.

التمرير السلس وRipple والانتقالات تُعطّل عند اختيار تقليل الحركة. لا يضيف هذا التطوير Service Worker أو تخزينًا قسريًا للكتالوج. تعذّر الاتصال لا يُفسَّر باعتباره اكتمال تنزيل أو تثبيت.
