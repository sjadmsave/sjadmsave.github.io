# المنهج — متجر التطبيقات العربية

متجر التطبيقات في `https://sjadmsave.github.io/almanhaj/`، ضمن مستودع الموقع الحالي. الواجهة عربية وتستخدم أنماط متاجر أندرويد: بحث ثابت، أقسام أفقية، قوائم تطبيقات مختصرة، تنقل سفلي للهاتف، ولوحات تفاصيل وترتيب سفلية.

## عقد النشر

- يبقى `catalog.json` مصدر البيانات الوحيد وبنفس `schema: 1`. يحدّثه APK Studio بعد اعتماد النشر؛ لا تُكتب بيانات التطبيقات داخل الواجهة.
- تُعرض التطبيقات ذات الحالة `published` وروابط APK الصحيحة من GitHub Releases. لا تنشئ الواجهة أي موافقة نشر، ولا تدير الإصدارات أو المسودات.
- تبقى معرّفات التطبيقات وأسماء الحزم والإصدارات والبصمات وروابط الملفات كما نشرها APK Studio.
- تظل إعدادات GitHub Pages في `.github/workflows/pages.yml` وجذر الموقع والتحميلات السابقة مستقلة عن تطوير واجهة المنهج.
- لا توجد أسرار أو رموز GitHub في الواجهة. لا يوجد Service Worker أو كتالوج مخزّن للعمل دون اتصال. يُجلب الكتالوج باستخدام `cache: no-store` وتُحدّث القائمة عند العودة بعد أكثر من دقيقة.

## ملفات الواجهة

- `index.html`: الهيكل العربي والأقسام واللوحات.
- `assets/store.css`: تصميم متجاوب، مظهران فاتح وداكن، حالات اللمس والظلال وتقليل الحركة.
- `assets/store.js`: التنقل والبحث والحفظ والمشاركة وإعادة المحاولة.
- `assets/catalog-core.js`: التحقق من الكتالوج والبحث العربي والفرز؛ مشترك مع الاختبارات.
- `assets/fonts/`: IBM Plex Sans Arabic محلي بأوزان 400 و600 و700، مع رخصة OFL. لا يعتمد الخط على خدمة خارجية.
- `manifest.webmanifest`: تشغيل مستقل عند الإضافة للشاشة الرئيسية، عند دعم المتصفح.

المحفوظات واختيار المظهر يبقيان محليين على الجهاز، باستخدام مفاتيح الإصدار السابق نفسها. يظل الحفظ متاحًا للجلسة عند منع التخزين المحلي، مع توضيح ذلك للمستخدم. لا توجد تقييمات أو أعداد تنزيلات مصطنعة.

روابط التطبيق المباشرة تستخدم `#view=discover&app=<encoded-id>`. يغلق زر الرجوع تفاصيل التطبيق وقائمة الترتيب قبل مغادرة الصفحة، وتستعاد التصفية وموضع التمرير عند الرجوع. يدعم زر المشاركة واجهة المشاركة في الهاتف، ثم نسخ الرابط أو عرضه يدويًا بحسب إمكانيات المتصفح.

## التحقق

من جذر المستودع، دون تثبيت اعتماديات:

```sh
node almanhaj/tests/smoke.cjs
node --test almanhaj/tests/catalog.cjs
```

تشغّل `.github/workflows/almanhaj-checks.yml` هذه الفحوص لطلبات الدمج وتحديثات فروع التطوير. لا تغيّر آلية النشر الإنتاجية.

للتشغيل المحلي من مجلد `almanhaj`، استخدم خادم HTTP ثابتًا. يلزم HTTP أو HTTPS لقراءة الكتالوج. تتطلب بعض إمكانيات المشاركة والحافظة HTTPS. تفاصيل التحقق المرئي وحدوده في [QA.md](QA.md).
