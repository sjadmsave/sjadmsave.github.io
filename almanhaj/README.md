# المنهج — ALMANHAJ

متجر عام داخل sjadmsave.github.io/almanhaj/، دون تغيير جذر الموقع القديم.

- catalog.json هو سجل الإصدارات المعتمدة. يبدأ فارغاً.
- جميع عمليات النشر والإخفاء تتم بعد موافقة صريحة من داخل APK Studio.
- الموقع لا يحتوي على رمز GitHub أو أي مفتاح خاص.
- إخفاء بطاقة من الموقع لا يلغي روابط APK العامة ولا يسحب نسخ المستخدمين السابقة؛ سحب الإصدار من GitHub إجراء منفصل.

## واجهة المتجر

- `index.html` هو مدخل الواجهة، مع ملفات العرض والسلوك في `assets/store.css` و`assets/store.js`.
- `catalog.json` يبقى **مصدر البيانات الوحيد**، بالصيغة `schema: 1` التي يحدّثها APK Studio. لا تُدخل بيانات التطبيقات يدويًا في الواجهة.
- تُعرض السجلات التي حالتها `published` ولديها رابط APK صالح من GitHub Releases فقط. هذه تصفية للعرض، وليست موافقة نشر بديلة.
- البحث والتصنيفات والفرز ومعلومات الإصدار وبصمات التحقق تعمل من البيانات الحالية.
- مظهر الهاتف يتبع Material-style interactions وشريط تنقل سفلي، مع احترام خيار تقليل الحركة.
- المحفوظات والمظهر الداكن إعدادات محلية في متصفح الزائر فقط؛ لا ترسل بيانات إلى خادم ولا تغيّر سجل النشر.
- `manifest.webmanifest` والأيقونات يتيحان تشغيل الموقع بوضع `standalone` عند إضافته إلى شاشة هاتف Android؛ لا يغيّران طريقة نشر GitHub Pages.
- لا يوجد Service Worker ولا تخزين مؤقت قسري لفهرس التطبيقات، حتى تظهر موافقات النشر والسحب الجديدة عند التحديث.

للمعاينة محليًا من داخل مجلد `almanhaj`:

```bash
python3 -m http.server 5173
```

شغّل الموقع عبر HTTP وليس `file://` حتى يستطيع قراءة `catalog.json`.

فحص اتساق المتجر دون تثبيت أي اعتماديات:

```bash
node tests/smoke.cjs
```
